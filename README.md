Healthcare Chatbot : AI-Based Symptom Analysis

Healthcare Chatbot is a web-based application that allows users to enter their symptoms and receive a predicted condition using a machine learning model.

The application combines a React.js frontend with a Python Flask backend and a Random Forest classification model to provide symptom-based predictions, condition descriptions, and precautionary information.

Key Features

Interactive chatbot interface.

Symptom-based user input.

Machine learning-based condition prediction.

Condition descriptions and precautionary information.

Conversational symptom collection.

React frontend integrated with a Flask backend.

Technology Stack

Frontend: React.js, JavaScript, CSS

Backend: Python, Flask

Machine Learning: Scikit-learn, Random Forest

Data Processing: Pandas, NumPy

Model Storage: Pickle

How It Works

The user enters their symptoms through the chatbot.

The application collects additional information, including symptom duration.

The frontend sends the information to the Flask backend.

The machine learning model processes the symptom data and predicts a condition.

The application displays the prediction along with its description and precautionary information.
